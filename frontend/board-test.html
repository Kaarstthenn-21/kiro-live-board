Instrucciones de Configuración

  1. Despliega el backend usando SAM: 
    sam build
sam deploy --guided
  2. Copia la URL de API Gateway de los outputs de SAM
  3. Abre board.html y reemplaza YOUR_API_GATEWAY_URL_HERE con tu URL
  4. Sirve los archivos HTML usando un servidor HTTP local o ábrelos directamente en el navegador
