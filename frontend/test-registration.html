Form Validation Tests

  • Submit button is disabled on initial page load
  • Submit button remains disabled when consent checkbox is unchecked
  • Submit button remains disabled if any required field is empty
  • Submit button enables only when ALL fields are filled AND consent is checked
  • Email field validates email format (browser validation)

Field Presence Tests (Requirement 1.1, 8.1, 8.2)

  • Name field is present (text input)
  • Email field is present (email input type)
  • Company field is present (text input)
  • Role field is present (text input)
  • Interest field is present (dropdown/select)
  • Interest dropdown contains "AI & Machine Learning" option
  • Interest dropdown contains "Cloud Architecture" option
  • Interest dropdown contains "DevOps & Automation" option
  • Interest dropdown contains "Security" option
  • Interest dropdown contains "Data Engineering" option
  • Interest dropdown contains "Other" option
  • Consent checkbox is present (Requirement 1.2)

API Integration Tests (Requires Backend Deployment)

⚠️ Note: These tests require the API Gateway URL to be configured in registration.html. Replace YOUR_API_GATEWAY_URL_HERE with your actual API endpoint after deployment.
  • Form submits POST request to /register endpoint (Requirement 1.5)
  • Success message displays on 200 response (Requirement 1.6)
  • Form clears after successful submission
  • "Already registered" message displays on 409 response (Requirement 1.7)
  • Error message displays on 400 response
  • Error message displays on 500 response
  • Network error message displays when API is unreachable

Mobile Responsiveness Tests

  • Form displays correctly at 480px width (larger phones)
  • All input fields are easily tappable on mobile

UX/Accessibility Tests

  • All fields have visible labels
  • Required fields are marked with asterisk (*)
  • Form can be completed using keyboard only (Tab navigation)
  • Focus states are visible on all interactive elements

🔧 Configuration Instructions

Before testing API integration:
  1. Deploy the SAM template: sam build && sam deploy --guided
  2. Copy the API Gateway URL from the deployment outputs
  3. Open registration.html in a text editor
  4. Find the line: const API_URL = 'YOUR_API_GATEWAY_URL_HERE';
  5. Replace with: const API_URL = 'https://your-api-id.execute-api.region.amazonaws.com';
  6. Save and reload this test page
